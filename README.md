# Luna & Clover - Boho Kids Boutique

A beautifully designed e-commerce website for a children's boutique featuring boho-inspired clothing. This project showcases modern web development with React, unique animations, and an organic design aesthetic.

## Design Philosophy

Luna & Clover embodies a **boho, airy, gypsy, free spirit** aesthetic with:
- Soft pastel color palette (sage, blush, lavender, terracotta, cream)
- Organic shapes and flowing animations
- Hand-crafted feel with custom fonts and decorative elements
- Mobile-first responsive design

## Features

- **Product Catalog**: Browse inventory with filtering by category and age group
- **Shopping Cart**: Full cart functionality with quantity management
- **Upcoming Releases**: Preview upcoming collections with countdown timers
- **Holiday Sales**: View active and upcoming promotional events
- **Responsive Design**: Optimized for all device sizes
- **Smooth Animations**: Framer Motion powered transitions and interactions
- **Unique UI/UX**: Non-standard layouts with organic shapes and gradients

## Tech Stack

- **Framework**: React 18 with Vite
- **Styling**: Tailwind CSS with custom design system
- **Animations**: Framer Motion
- **Routing**: React Router DOM
- **No Backend Required**: Uses local mock data (perfect for portfolio)
- **No Paid Services**: 100% free and open source

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The site will be available at `http://localhost:5173`
